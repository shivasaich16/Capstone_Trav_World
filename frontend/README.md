# Frontend

Place the existing browser application here after exporting it from Replit.

Suggested mapping (confirm against the real source before moving files):
- HTML entry files -> `public/` or the framework's root
- CSS files -> `src/styles/`
- JavaScript UI modules -> `src/`
- reusable UI -> `src/components/`
- screens/pages -> `src/pages/`
- API calls -> `src/services/`

Do not assume the deployed app uses plain HTML/CSS/JS; check its package manifest and entry points first.
