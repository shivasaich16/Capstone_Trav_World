# TRAV-WORLD 
  Trav-World-Url : https://trav-world.onrender.com/

Local full-stack starter for the Trav-World-style experience and booking UI.

The backend uses a persistent JSON-file datastore in `backend/data/service-booker.json` to keep Windows setup simple and avoid native build dependencies. It supports demo experiences, account registration/login and booking request persistence.

This is a functional starter, not an exact source-code extraction of the deployed Replit app. Obtain the original Replit source to migrate its exact features and data model.

Run backend from `backend/` using `npm.cmd install` and `npm.cmd run dev`. Serve `frontend/index.html` with Live Server.
